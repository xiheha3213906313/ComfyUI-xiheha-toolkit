# xiheha-工具箱

这是一个面向个人扩展的 ComfyUI 自定义节点**工具库**，当前提示词配置模块包含五个节点：

1. **模型列表获取**：接收 ComfyUI 的 `MODEL`，原样输出并额外输出模型提示词配置源。
2. **easy-use兼容_模型列表获取**：只接收上游 easy-use 的 `LORA_STACK`（必选），原样输出并额外输出模型列表扫描数据。
3. **选择提示词配置**：扫描模型或 LoRA 同目录的 TXT/JSON sidecar，选择正向/负向配置。
4. **模型提示词控制**：按模型或 LoRA 显示正向和负向标签；点击标签可单独启用/关闭，灰色标签不会进入最终输出。
5. **提示词合并**：按端口顺序合并最多四段提示词。

## 安装

插件目录应位于：

```text
E:\HuiShi_launcher-WorkFisher-V2\ComfyUI\custom_nodes\xiheha-toolkit
```

安装或更新后重启 ComfyUI，并刷新浏览器页面。

## 配置文件

插件按以下顺序寻找模型或 LoRA sidecar：

```text
模型名.txt
模型名.json
模型名.safetensors.json
模型名.safetensors.txt
```

TXT 示例：

```text
正向：anime face, realistic hair,
负向：lowres, watermark,
正向2：another style,
负向2：bad anatomy,
```

相同编号会被视为同一个配置。选择提示词配置节点只显示配置按钮，不显示配置正文；模型提示词控制节点会分别显示正向和负向内容。

模型提示词控制节点中，正向或负向内容为空时会隐藏对应分区；两侧都为空时会隐藏整个模型区块。所有提示词默认启用，关闭状态会保存到工作流。

## 实时刷新说明

上游模型加载器改变模型、或 easy-use 简易 LoRA 堆改变当前 LoRA、数量或开关后，选择提示词配置会实时刷新；选择提示词配置改变配置后，模型提示词控制会实时刷新标签。正式输出字符串由 ComfyUI 在下一次队列执行时生成，前端不会自动触发采样。

## 开发

解析器和节点逻辑位于 `core/` 与 `nodes/`，前端扩展位于 `web/`（原生 ES Module：入口 `xiheha_toolkit.js`，共享能力在 `shared/`，每个节点一个 `nodes/*.js` 模块）。新增节点时，在独立模块中实现并在根目录 `__init__.py` 与前端入口登记即可。

面向 AI/开发代理的完整开发规范见同目录 `AGENTS.md`。修改前请先阅读，尤其注意节点 ID、工作流兼容、模型路径安全和测试流程。

运行测试：

```powershell
python -m unittest discover -s tests
```
